# saubhagya-resin-art

Resin art online store with login, design studio, and UPI orders.

This project contains the storefront and a Flutter starter app.

## Storefront

The static storefront starts at `index.html`. Open it in a browser or serve this
folder with a local web server. The VS Code Live Server port is configured as
`5501` in `.vscode/settings.json`.

Product images, videos, and review uploads are kept in `images/`, `REEL/`, and
`uploads/`.

## Flutter app

The Flutter starter project is in `flutter_app/`. Install the Flutter SDK, then
run:

```powershell
cd flutter_app
flutter pub get
flutter run
```
